# Library's site "One Star Library"

Веб-приложение для вымышленной библиотеки с каталогом книг, регистрацией пользователей, бронированием и административной панелью.

Проект разработан на Python с использованием Flask и SQLite. Интерфейс реализован с использованием HTML, CSS и JavaScript. Проект является лабораторной работой для предмета "Пользовательский программный интерфейс"

## Возможности

### Для пользователей

- просмотр каталога книг;
- поиск книг по названию, автору и жанру;
- регистрация и авторизация;
- валидация персональных данных при регистрации;
- безопасное хранение паролей в виде хэщей;
- бронирование книг;
- бронирование компьютеров библиотеки;
- просмотр новостей библиотеки;
- адаптация интерфейса для пользователей с особыми протребностями.

### Административная панель

- просмтотр зарегистрированных пользователей;
- добавление и удаление книг;
- просмотр и удаление бронирований;
- добавление и удаление новостей;
- загрузка изображений для новостей;
- просмотр бронирований книг.

## Доступность

В приложении предусмотрена специальная версия интерфейса для слабовидяящих пользователей:

- увеличение размера шрифта;
- переключение шрифта с засечками;
- черный текст на белом фоне;
- желтый текст на черном фоне;
- вомзожность скрыть изображения;
- сохранение настроек пользователя в браузере.
